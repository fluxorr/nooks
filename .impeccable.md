# Design Context

## Product
**Nooks** - A link curation tool that helps users save, organize, and search across web content they care about. Each link gets auto-summarized and stored in themed collections called "Nooks."

## Users
- **Mixed / open** - Designed for anyone who saves too many links
- Primary context: Personal knowledge management, content curation, research
- User needs: Speed, clarity, minimal friction

## Brand Personality
**Clean, fast, minimal** - Three-word descriptor

- Prioritize speed and efficiency over ornamentation
- Content (links) should be the hero, not the UI
- No clutter, no unnecessary visual weight

## Aesthetic Direction
- **Linear-style** references - Clean, minimal, keyboard-driven, seamless dark/light modes
- Subtle grain texture (already implemented)
- Warm earthy theme (cream/amber) but keep it light and crisp
- Animations should be purposeful and quick, not decorative

## Design Principles

1. **Content-first** - Links and their summaries are the focus; UI recedes
2. **Speed = trust** - Every interaction should feel instant; no loading states unless necessary
3. **Keyboard-friendly** - Support shortcuts (⌘⇧S), tab navigation, clear focus states
4. **Accessibility baseline** - WCAG AA, respect prefers-reduced-motion, optimized for screen readers
5. **Consistent across surfaces** - Landing, dashboard, save page, extension should feel like one product

## Technical Design Tokens

### Colors (already defined)
- Background: `#faf8f5` (light) / `#1a1915` (dark)
- Accent: `#d97706` (amber)
- Muted text: `#6b685e`
- Border: `#e8e4dc`

### Typography
- Font stack: Apple system fonts (SF Pro Display, SF Pro Text)
- Bold headers, readable body text

### Spacing & Components
- Generous whitespace, comfortable padding (p-4, p-6, p-8)
- Cards with subtle borders, no heavy shadows
- Glassmorphism for sticky headers and modals

## Anti-References
- Should NOT look generic or "AI-slop"
- Should NOT be overly playful or cartoonish
- Should NOT have heavy gradients or skeuomorphic elements
